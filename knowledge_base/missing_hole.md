# Missing hole

## Description
A drilled hole or via that should exist on the board is absent, so a pad or via has no through-hole.

## Likely causes
Drill bit breakage or a skipped drill step, wrong drill file, or a worn bit that failed to penetrate.

## Severity
High for through-hole component pads and vias because the part cannot be mounted and layers may not connect.

## Recommended action
Quarantine the board, check the drill program and bit condition, and re-drill only if the customer specification allows rework. Otherwise scrap the board.
